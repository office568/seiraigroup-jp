代表挨拶

基本を、高い水準で。

私たちに得意なことがひとつあるとすれば、それは基本です。

すべてのスタッフが同じ水準で動けるように育て、会社のミッション、ビジョン、価値観を共有することで、より高いサービスを目指しています。目指すものが同じだから、チームにリズムと勢いと調和が生まれます。連携が良ければ仕事は速くなり、間違いは減り、それがゲストの満足につながります。

株式会社セイライグループジャパン代表取締役　シリカン アサワ

私たちについて

理念、ビジョン、ミッション。

私たちが何を約束し、どこを目指し、何を届けているのか。

  1. 01経営理念

    約束を守ることで、信頼をいただく。

    高水準を約束し、その約束を事業のあらゆる場面で守り続けること。それが、私たちが関わるすべての方から信頼をいただく方法だと考えています。

  2. 02ビジョン

    日本で最も愛される、家族のためのホスピタリティブランドへ。

    家族を第一に考えた、プライベートで、家のようにくつろげる選択肢。ロビーも堅苦しさもなく、快適さと便利さ、そしてプライバシーがある場所を目指しています。

  3. 03ミッション

    家族が、ともに思い出をつくれる場所を。

    プライベートで清潔、快適な宿泊施設に、親しみのあるサービスと一人ひとりに合わせた体験を添えて。最新のテクノロジーで、滞在をより快適に、より便利にします。

経営理念

高水準を約束する、その考え方。

高水準を約束し、それを守り続けるために、私たちが大切にしている考え方です。

  1. 01信頼がブランドをつくる

    ブランドをつくるのは広告ではなく、信頼です。レビューも、ご紹介も、リピーターも、広がっていくパートナーシップも。すべては、約束を一つずつ守ることで得た信頼から生まれます。

  2. 02基準こそ最大の資産

    高い基準で仕事をすることで、ゲストが私たちのもとで出会う驚きを、良い驚きにします。

  3. 03利益より誠実さ

    ゲスト、スタッフ、パートナー、株主。誰に対しても約束を守ります。至らなかったときは正直に認め、正しい方法で直します。

  4. 04成果に報い、成長に投資する

    成果を出した人には、それにふさわしく報います。そして、成果を生み出す人の成長に投資します。

  5. 05卓越は価値を生む

    最高の水準で運営するとき、ゲスト、従業員、オーナー様、そして地域のすべてに価値が生まれます。

  6. 06基準を守れば、誇りがついてくる

    基準 → 約束 → 信頼 → 誠実 → 成果 → 価値 → 誇り。誇りは正しく仕事をした証であって、仕事をする理由ではありません。
